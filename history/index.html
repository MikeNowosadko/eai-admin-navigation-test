Four passes at the same four questions

Every version installs the app, signs you in, and ends in your own coding app. What changed is how much the person is asked to carry. Each one is still live at its own URL, so any of them can be opened and clicked through.

v1 Four prerequisite ticks to read. Three questions on one screen.
v2 Prerequisites hidden. One question per screen — four Continues.
v3 One page. Answering reveals the next question. No Continue.
v4 The workspace's standard decides. Everything else collapses.
v1

The full form

The baseline. The app opens on a checklist of four green ticks, then asks for the project name, the parent folder and your coding app on a single screen.

  • The problem it revealed. Four ticks is four lines of reassurance about work nobody asked to see, read before you have done anything.
  • And the other one. Three unrelated questions on one screen means three chances to be wrong before any feedback.

v2

Prerequisites go quiet

Node, Git, npm and the CLI install while the app is being copied to Applications, and are never mentioned unless one fails. Then one question per screen, and the workspace question the real installer has and v1 skipped.

  • What it got right. The failure became the only time prerequisites exist for the user — which is the only time they are the user's problem.
  • What it got wrong. Fewer decisions per screen, but four Continues to get through them. A click that only means “yes, I did just answer that” is a click worth deleting.

v3

One page, no Continue

The window opens big enough to hold the whole form. Choosing a workspace reveals the name field; naming reveals the folder; choosing a folder reveals the button. Answered steps stay on screen and stay editable.

  • The check came back, stated. v1 made you read a report, v2 left you wondering whether anything happened. One line says the Mac is ready, and expands into the full list only when something failed.
  • Nothing opens itself. Finishing setup and leaving for your editor are two intentions, and the second one is the user's.
Open v3 →
v4 current

The workspace decides

The last question — which AI app you build in — stops being a list of six. An administrator sets the standard in workspace settings, so it gets a box of its own and everything else collapses behind it. Most people see one box and one button.

  • Not having one is handled. Most of these are npm packages and setup installed npm a minute ago, so it offers to install them. VS Code is an app download, and says so.
  • What it can't do, it says. Installing a tool doesn't get you an account, so the alert above the button always names what it will ask for next.
  • No standard set? No box. A note points at the administrator who could set one, and the whole list opens.
