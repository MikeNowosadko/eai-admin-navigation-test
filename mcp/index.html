8

One rule, whatever we pick.

Every question gets written as words first, and must be answerable by typing. The nice boxes are a kinder way to answer the same question — never a different one, never an extra one.

Otherwise the person on a black screen
is playing a different game from the person in a window — and we'd be building two products.
