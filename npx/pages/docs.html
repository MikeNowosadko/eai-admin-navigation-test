Get Started

Follow the 5 steps below to get started with Enterprise AI.

Step 1

Pick your app

All four options are supported equally. The page auto-selects macOS or Windows, but you can change it at any time.

Step 2

Open Codex

Open Codex. Pick or create the folder where this project will live. Make sure Codex is using that folder before moving on.

Downloads land in your dock, ready to open.
Step 3

Paste the setup prompt into Codex

One prompt does the whole setup: installs the CLI, signs you in, and creates the project.

Set up this folder as an Enterprise AI project. 1. Install the EAI CLI (npx install eai) and the eai-gofer workflow pack. 2. Sign me in to EAI in the browser, then confirm my workspace. 3. Run: eai init <project-name> --skip-prompts --tenant <tenant-id> 4. Stop and wait for me to type /0_business_scenario. Ask me to confirm the folder, project name and company tenant before you run init. Only stop if something unexpected happens.
The prompt is the same for every app — only the place you paste it changes.
Step 4

Finish setup, then open your project

Follow Codex prompts through sign-in. Before eai init runs, you will confirm a few things so it can skip the CLI questions and only stop if something unexpected happens.

  1. Approve the actions Codex asks for — you may need to click Approve or type yes so setup can keep moving.
  2. Complete browser sign-in if it opens — finish in the browser, then return to Codex.
  3. When prompted, confirm folder, project name, and company tenant — Codex will then run eai init <project-name> --skip-prompts --tenant <tenant-id>.
  4. Keep the setup bound to your signup workspace — for Builder, use the Builder workspace, not EAI Developers. Create apps or child companies later from Apps or the EAI CLI.
  5. Point Codex at the new project folder — if it does not switch automatically, open the folder path the setup shows you as the active workspace.
  6. Type /0_business_scenario followed by the app you would like to build — explain as much as you can about what you want to build, then press Enter. It may take a few minutes to work through all the build steps.
Step 5

Start the business scenario and keep iterating

Describe the business problem, answer the clarifying questions, then approve or feed back on what comes out. Keep going until it does what your team needs.
