Getting started flows

Each card is a complete, clickable journey from first search to a deployed app. Built to answer one question: can someone actually get set up without help?

Inside a flow there's no prototype chrome — press ⌘K for controls (back here, restart, switch app), or use the Apple menu. esc closes it.
