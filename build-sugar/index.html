What it does
  1. 1.
    Starts from what you have. Uses the Claude Code, Cursor, or Copilot subscription you already pay for — no second agent.
  2. 2.
    Maps the process first. Workshop mode understands how work runs today before a line of workflow is built.
  3. 3.
    Lets you change your mind. Iterate on blocks and routing in the harness, then sync back to Enterprise AI.
  4. 4.
    Hands off cleanly. A real folder on disk, ready for /eai and your existing git flow.
  5. 5.
    Ships with governance. Tenancy, audit, and smart blocks — not a one-off script.
What it needs

A Mac running macOS 14 or later. A harness you already use — Claude Code, Cursor, Copilot, or Codex. An EAI account once you are ready to deploy; not before the workshop opens.

What it is not
  • Not another coding agent competing with Claude or Copilot.
  • Not a mockup tool — the output is a real app folder your harness can implement.
