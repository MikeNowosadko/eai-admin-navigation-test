Split desktop — unified window

How Enterprise AI nests inside an external harness (DesignEx-style), with our app in a first column and our injection under the harness chat.

Prototype: build-sugar/shell.html · Launch pad item 2

The journey

  1. Install — drag EAI Setup to Applications (macOS shell).
  2. Sign in — two-column setup window: sign-in left, EAI warp shader right.
  3. Harness + location — pick external harness and confirm default project folder; shader stays on the right.
  4. Start — window animates to full-screen unified app (below).

Unified window

After Start, the window expands full-screen. The external harness (DesignEx reference) loads inside the Enterprise AI app — not a separate right column.

Design decisions

  • Fewer clicks before wow — no workspace, app name, or folder chooser in setup. Default project path; naming happens in the harness.
  • Shared auth assumed — sign-in through the harness can share session with Enterprise AI later.
  • DesignEx as reference harness — we copy their shell faithfully first, then iterate on injection + EAI column.
  • Prototype vs ship — HTML simulates nested harness; native would be WKWebView + child process (see install-5 pattern).
